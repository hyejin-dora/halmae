# 올해의 카드 · 테마별 카드 아트

여기에 그림 파일을 넣으면 카드 가운데 그림이 fallback 아트에서
실제 일러스트로 바뀝니다. **코드는 고치지 않습니다.**

## 파일 이름 (visual_theme 값 그대로)

| 파일 | 그리는 장면 |
| --- | --- |
| `breakthrough.png`   | 갈라진 대지를 뚫고 솟는 나무 |
| `expansion.png`      | 빛이 새는 열린 문과 넓게 뻗은 가지 |
| `balance.png`        | 해와 달이 마주 선 대칭의 산 |
| `transformation.png` | 껍질을 벗고 새로 자라는 나무 |
| `grounding.png`      | 돌 위에 깊게 뿌리내린 고목 |
| `connection.png`     | 두 존재를 잇는 한 줄기 붉은 실 |
| `clarity.png`        | 안개가 걷히자 드러나는 달과 길 |
| `renewal.png`        | 새벽빛을 받고 올라오는 새싹 |

`.png` 대신 `.webp` · `.jpg` · `.svg` 를 넣어도 같은 이름이면 알아서 찾습니다.
여덟 장을 한꺼번에 채울 필요는 없습니다. 넣은 테마만 그림으로 바뀌고,
나머지는 계속 fallback 아트가 나옵니다.

## 그림 규격

- 세로 3 : 4 (예: 900 × 1200)
- 파일 하나당 6MB 이하 (넘으면 fallback 으로 내려갑니다)
- 가장자리는 잘릴 수 있으니 주인공을 가운데 두고 여백을 넉넉히
  (칸을 `object-fit: cover` 로 채웁니다)
- 그림 위에 금색 프레임과 귀퉁이 문양이 겹쳐 올라갑니다.
  네 귀퉁이에 중요한 것을 두지 마세요.

## 어떤 그림을 그릴까

테마별 지시문이 코드 안에 문장으로 들어 있습니다.
그대로 이미지 생성 모델에 넣으면 화면과 결이 맞습니다.

```bash
python card_visuals.py     # 여덟 테마의 프롬프트 + 파일 유무
```
